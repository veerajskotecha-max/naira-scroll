# NAIRA PETITE — The Petite Index (A4, one page)

Every Naira Petite jewellery listing on nairaflore.com on 1 October 2026: **55 listings, 38 in stock,
17 sold out**, each with its photograph, name, SKU code, metal (dot legend) and live price.

| File | Use |
|---|---|
| `naira-petite-index-A4.pdf` | Print on any A4 printer, or share |
| `naira-petite-index-A4-PRINT-3mm-bleed.pdf` | Print shop master: 216 × 303 mm, 3 mm bleed, TrimBox = A4 |
| `naira-petite-index-A4-preview.png` | Quick look on a phone |

Layout: an 8 × 8 grid. Four family tiles (Earrings 15, Rings 13, Necklaces 14, Bracelets & Set 13)
open each group; within a group, in-stock pieces come first by price, then sold-out pieces, faded and
tagged. The last tile is a QR code to nairaflore.com.

Data: `build/skus.json` is the live Shopify product feed reduced to title, type, SKU, price, availability
and tags. Photos are the cream-plinth Shopify shots used in the catalogue; sold-out pieces use their own
plinth shot. The 18 couture listings are not included.
